Privacy Policy

This website serves exclusively as a technical proxy (redirect) to authorize local ESP microcontrollers with the Spotify API. It is operated purely as an open-source hobby project without any commercial intentions.

1. Data Collection by this Website

As the operator of this website, I do not collect, process, or store any personal data from you.

  • The authorization code provided by Spotify and the local IP address passed in the link are only read client-side (in your browser).
  • No data is transmitted to servers owned or operated by me.
  • No cookies, tracking tools (such as Google Analytics), or web fonts (such as Google Fonts) are used.

2. Hosting via GitHub Pages

This website is hosted by the following third-party provider:
GitHub Inc., 88 Colin P Kelly Jr St, San Francisco, CA 94107, USA.

Every time this website is accessed, GitHub's system automatically collects data and information from the computer system of the accessing computer. The following data may be stored temporarily in the server log files:

  • Information about the browser type and version used
  • The user's operating system
  • The user's IP address
  • Date and time of access

This data is stored in log files by GitHub to ensure the functionality of the website and the security of its information technology systems. For more information on data protection at GitHub, please refer to the GitHub Privacy Statement.

3. Data Transfer to the USA

Please note that by hosting with GitHub, data may be transferred to the USA. GitHub is a US company. The data transfer is based on standard contractual clauses or adequacy decisions (Data Privacy Framework).
